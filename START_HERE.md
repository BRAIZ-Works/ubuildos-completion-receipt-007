# Start Here

1. Open the live demo: https://braiz-works.github.io/ubuildos-completion-receipt-007/
2. Review the visible queue rules in the app or `README.md`.
3. Inspect a row's aging, computed priority, and reason.
4. Use **Manual override** and enter a reason; verify the original computed priority remains visible.
5. Use **Export CSV** to export the current queue.
6. Review `LIMITATIONS.md`, `PRIVACY.md`, and `SECURITY.md` before treating the demo as anything beyond a bounded workflow example.

The demo uses synthetic data and performs no payment, banking, accounting, customer-contact, credit, legal, or collection action.
