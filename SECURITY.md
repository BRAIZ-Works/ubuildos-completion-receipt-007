# Security

## Public build boundary

The application is a static client-side demonstration with no authentication, payment rail, bank/accounting connector, customer messaging integration, backend database, or secret-bearing runtime configuration.

The public release is intended to contain only synthetic demo data, static runtime files, bounded documentation, and integrity records.

## Reporting

Do not publish credentials, private customer information, exploit details, or other sensitive material in a public issue. Use the private GitHub security/contact route described in `SECURITY_CONTACT.md` when available.

## Non-claim

These checks establish the bounded public-release security properties evaluated for this project. They are not a certification or guarantee that every possible vulnerability is absent.
